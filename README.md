# DaoFlash

DaoFlash is a decentralized data pipeline manager for event-driven, real-time analytics and system optimization.

DaoFlash is built to be simple and practical, focusing on doing one thing well.

**Why DaoFlash?**

- DaoFlash is a decentralized data
- pipeline manager for event-driven, real-time
- analytics and system optimization

## Key Features

- DaoFlash is a decentralized data
- pipeline manager for event-driven, real-time
- analytics and system optimization

## Technology Stack

- rust
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoFlash.git`
2. `cd DaoFlash`
3. Install in editable mode: `pip install -e .`

## Configuration

DaoFlash is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
